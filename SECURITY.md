# Security Policy

## Supported versions

Security fixes are applied to the latest published release and the current `main` branch.

## Reporting a vulnerability

Do not include sensitive details in a public issue. Use GitHub's private vulnerability reporting feature for this repository. If private reporting is unavailable, open a public issue that only asks the maintainer to establish a private contact channel.

ImpactBar reads local EVE combat logs and does not intentionally perform network requests. Reports involving unexpected network access, unsafe file handling, or release integrity are especially useful.
