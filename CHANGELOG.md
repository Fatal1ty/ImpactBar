# Changelog

All notable changes to ImpactBar are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.3.0] - 2026-11-18

### Added

- Feature-specific enable controls for turret hit quality and energy neutralizers.
- A reorganized menu with feature, appearance, sound, testing, and utility sections.
- Menu icons, per-overlay position reset actions, and a global reset action.
- A native About panel with version information and a GitHub link.
- A custom app icon and permanent bundle identifier.
- Universal release packaging and GitHub release automation.

## [0.2.2] - 2026-11-18

### Added

- Compact energy-neutralizer overlay with last-cycle and per-target totals.
- Draining, dry, pinned, and recovered state detection.
- Neutralizer sounds and test controls.
- Three-segment activity cadence indicator.
